# Security Policy

## Reporting a vulnerability

Please report security issues privately, never in a public issue.

- Preferred: GitHub's "Report a vulnerability" button (Security tab of the repository).
- Or by email: bonjour@yanisblanchard.com

I will acknowledge your report within 7 days and keep you informed until it is resolved.

## Supported versions

Only the latest version on the `main` branch receives security fixes.
